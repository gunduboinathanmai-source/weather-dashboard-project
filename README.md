
🌦️ Weather Dashboard

A modern and interactive Weather Dashboard built using HTML, CSS, and JavaScript.
This project provides real-time weather updates including temperature, humidity, wind speed, pressure, weather condition, live city time, dynamic backgrounds, dark mode, and location-based weather support using the OpenWeather API.

✨ Features

✔️ Search weather by city name
✔️ Current location weather support
✔️ Live temperature, humidity, wind & pressure
✔️ Dynamic weather icons and backgrounds
✔️ Real-time city time display
✔️ Dark mode support

🛠️ Tech Stack

HTML • CSS • JavaScript • OpenWeather API
